# Brand kit history: 2026-11-09

The notes in this folder are the brand kit's own records as delivered on
2026-11-09, while every rule in them was still a proposal. They are kept as a
historical snapshot and are not maintained. What batlog adopted, and how to
use and change it, is in [docs/reference/brand.md](../../../../docs/reference/brand.md).

| File | What it recorded |
|---|---|
| `kit-README.md` | The kit's README: the files and how to rebuild them |
| `brand-information.md` | Naming, product facts, voice, and the proposed colour, type and usage rules |
| `app-alignment.md` | How the kit related to the app's terminal styles at the time |
| `brand-tokens.json` | The kit's proposed palette; `brand/tokens.json` replaces it |
| `provenance.json` | Hashes of the kit's inputs: the supplied JPEGs, the fonts and two app snapshots |

Edits since delivery: personal folder references were removed, and this
snapshot note was added to each Markdown file. Paths in these notes
(`source/`, `svg/reconstructed/`, `ready-to-use/`) are the kit's original
layout, not this repository's.
